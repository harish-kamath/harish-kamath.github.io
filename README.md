# hkamath.me

Personal site, built with plain Jekyll.

- Write posts in `_posts/` as `YYYY-MM-DD-slug.md`. Add `math: true` to the front matter for LaTeX.
- Drafts live in `_drafts/` and are not published.
- Pushing to `master` builds the site and publishes it to the `gh-pages` branch, which serves hkamath.me.

Local preview:

```
bundle install
bundle exec jekyll serve
```
